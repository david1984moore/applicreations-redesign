Marketing site and intake app. No database, no auth, no CMS. Copy lives in TypeScript dictionaries; transactional email is the only outbound service.

Architecture
Next.js App Router with a root layout (fonts, metadata, CSS) and a locale layout that wraps every page in Navigation, footer, and a React context dictionary. English URLs have no prefix; Spanish uses /es. Middleware rewrites bare English paths into /en/... for the [locale] segment and redirects /en away so it never appears in the URL.

TypeScript and tooling
Target ES2017, moduleResolution bundler, isolatedModules, Next plugin. Path alias @/* → repo root. Scripts: dev (next dev -p 3004), build, start, lint, type-check, pre-commit, clean, reset. next.config.ts only sets outputFileTracingRoot.

Design system (in-repo, not a package)
OKLCH tokens in app/globals.css @theme: paper/sand/sky, primary blue scale, 8-point spacing, Perfect Fourth type scale, Fraunces display + Source Sans body. Reduced-motion media query. Coastal wash/grain utilities. Custom UI: Button, Card, Input, Link, Badge, Progress, SpectrumFlipCta, BrandNavLinks — not a full shadcn install.
